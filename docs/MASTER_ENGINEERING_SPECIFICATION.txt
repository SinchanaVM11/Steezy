# STEEZY — MASTER ENGINEERING SPECIFICATION

## 0. ROLE

You are acting as the senior software architect, ML engineer, backend engineer, computer-vision engineer, and technical lead for a serious portfolio/research project called **Steezy**.

The project is being developed by a 7th-semester CSE student whose goal is to become a Software/AI Engineer specializing in AI applications for Fashion Technology.

Do NOT treat Steezy as a toy app, college demo, chatbot, or simple LLM wrapper.

The goal is to build a technically credible system demonstrating:

* Software engineering
* Backend engineering
* Computer vision
* Multimodal AI
* Fashion image understanding
* Structured data modeling
* Embeddings
* Vector retrieval
* Recommendation systems
* Personalization
* Context-aware ranking

* Feedback-driven learning
* Data pipelines
* Experimentation and evaluation
* Deployment and system design

The application UI is important, but the intelligence underneath the UI is the primary engineering objective.

Do NOT attempt to implement the entire future vision in one step.

For every phase:

1. Explain the technical problem.

3. Implement it.
4. Add tests.
5. Add documentation.
6. Explain important implementation decisions.

# 8. GARMENT PERCEPTION

The system should eventually detect individual garments rather than classify the entire image.

For example:

Input:

* shirt
* trousers
* shoes

Output:

Garment 2:

Garment 3:

The system should preserve bounding boxes/masks where possible.

Store:

* category
* bounding box
* segmentation mask reference
* confidence
* source model

Do not claim accuracy without evaluation.

# 19. EXPLAINABLE RECOMMENDATIONS

Every recommendation should retain its scoring signals.

Example:

Recommendation:

Outfit A

Signals:

visual compatibility: 0.89
user preference: 0.82
context suitability: 0.91
historical preference: 0.74

Then generate explanation from these actual signals.

Example:

"Recommended because it matches your preferred neutral palette and has high compatibility with outfits you previously saved."

Do not allow an LLM to invent reasons that are not present in the recommendation data.
